# Security policy

Leeway reads the sign-in tokens of Claude Code and Codex on your Mac. Please report anything that could expose them, or any other security problem, in private.

## Report a vulnerability

Use [Report a vulnerability](https://github.com/aliaks-ei/leeway/security/advisories/new) on the Security tab. Do not open a public issue.

Include the Leeway version, the macOS version and the steps that show the problem. You get an answer within 7 days.

## Supported versions

Only the latest release gets fixes.
